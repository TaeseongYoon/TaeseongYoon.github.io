# Taeseong Yoon — Academic Homepage

Upload the following items to the root of `TaeseongYoon.github.io`:

```text
index.html
style.css
assets/
  KakaoTalk_20260701_191512705.jpg
```

The photo path in `index.html` is:

```html
<img src="assets/KakaoTalk_20260701_191512705.jpg" ...>
```

The filename and capitalization must match exactly on GitHub Pages. This package already includes the image in the correct location.

After uploading, wait briefly for GitHub Pages to rebuild and then hard-refresh the page (`Ctrl+F5`). The stylesheet URL has a version query to reduce stale-cache issues.
